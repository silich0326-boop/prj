# 실제 AI 에이전트 최종 검증

아래 항목은 아직 실측 완료되지 않았습니다. 코드·모의 테스트의 성공을 실제 모델 성공으로 기록하지 않습니다. 과제의 수업용 키를 사용해 각 질문을 한 번씩 검증하고, 실패한 항목만 수정 후 재검사합니다.

## 준비

1. 로컬 `.env.local`과 Vercel 환경변수에 `ANTHROPIC_API_KEY`를 등록합니다.
2. 안내서 지정 `ANTHROPIC_MODEL=claude-sonnet-5-5`를 사용합니다. 계정에서 모델을 사용할 수 없다는 오류가 나오면 임의로 비싼 모델로 바꾸지 말고 강사에게 확인합니다.
3. Vercel을 재배포하고 `/api/hello`의 `hasClaudeKey`를 확인합니다. 키 설정 여부 확인은 실제 모델 접근 성공을 의미하지 않습니다.
4. 배포본 `/agent`에서 아래 질문을 검사합니다. 최대 루프 5회·최근 기록 10개·출력 토큰 1024 제한을 유지합니다.

## 안내서 기본 질문

| 질문 | 확인할 행동 | 현재 실측 결과 |
|---|---|---|
| 제주시 지금 날씨 어때? | `get_weather` 호출. 반환된 예보와 현재 관측을 혼동하지 않음 | 미검증 |
| 관덕정이 어떤 국가유산이야? | `search_heritage` 호출 및 결과에 근거한 답변 | 미검증 |
| 내일 서귀포에 비 오면 해녀 문화를 체험할 실내 장소 추천해줘 | 날씨·관광 등 도구 2개 이상 연속 호출, 반환된 예보 시간 범위 확인 | 미검증 |
| 제주에 있는 에펠탑 알려줘 | 실제 조회 후 등록 자료가 없음을 안내하고 장소를 만들지 않음 | 미검증 |
