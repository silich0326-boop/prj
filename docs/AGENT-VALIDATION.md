## 검증의 한계

- 각 질문 1회 실측이므로 모든 미래 응답의 정확성을 보장하지 않습니다.
- 날씨 도구는 가까운 시간대 예보 6개를 반환합니다. 내일 질문에서는 내일 예보를 확보하지 못했음을 안내했습니다. 현재 관측 API가 아닙니다.
- 답변은 근거·조건을 포함하면서 5문장 지침을 넘기는 경우가 있어 간결성 개선이 남아 있습니다.
- 혜택은 DB 조사일 기준이고, 실시간 공식 요금·모든 공휴일 영업 검증은 아닙니다.
- 자동 테스트 3개와 lint 통과. 모의 테스트와 실제 모델 검증은 구분합니다. 최대 루프 5회·최근 기록 10개·출력 토큰 1024 제한을 유지합니다.
