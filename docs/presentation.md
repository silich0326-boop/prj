# 제주 스토리 발표 구성

## 1. 기획
제주 문화·자연을 콘텐츠 창작의 출발점으로 연결하는 웹앱. 대상은 제주 콘텐츠를 기획하는 학생·창작자입니다.

## 2. 사용자 흐름
홈 → 콘텐츠 검색 및 분류 → 3D 지도 핀 선택 → 영감 저장 → AI에게 문화·날씨 질문.

## 3. 기술
Vite + React, Router, Zustand, Bootstrap, Supabase, Three.js. Vercel 서버 함수로 비밀키를 보호합니다.

## 4. 데이터 3종
관광공사 TourAPI, 기상청 단기예보, 국가유산청 API. 에디토리얼 예시와 실시간 데이터를 화면에서 구분합니다.

## 5. AI 도구
질문 → 도구 선택 → 실제 API 조회 → tool_result 전달 → 한국어 답변. 도구 실행 내역을 표시합니다.

## 6. 시연
검색 → 저장 및 새로고침 → 3D 회전·핀 선택 → DB 검사 → 공공데이터 조회 → AI 질문. 외부 연동은 키 설정과 실호출 검증이 필요합니다.

## 7. 한계 및 발전
일러스트 지도는 개략적인 위치. 실시간 API 승인 및 AI 계정 설정 필요. 다음 개선: 계정 로그인, 기기간 저장 동기화, API 캐싱, 정밀 지도.

## 8. 제출
GitHub 및 Vercel URL은 실제 업로드·배포 후 기입합니다.
