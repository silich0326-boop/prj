# 제주 스토리 3분 발표 대본

제주도민의 혜택 우선 문화·여가 여행 서비스입니다. 발표자는 확인된 동작만 시연합니다. 2026.11.02 배포본에서 실제 AI 질문 7건과 브라우저의 날씨·혜택 도구 호출을 검증했습니다. 이 파일은 슬라이드 구성과 발표 대본 초안이며 PPTX 파일은 아닙니다.

## 발표 구성

| 구간 | 시간 | 화면 | 핵심 메시지 |
|---|---|---|---|
| 문제와 대상 | 0:00~0:25 | 홈 | 도민 혜택과 이용 조건이 흩어져 있음 |
| 서비스와 제주 문화 | 0:25~0:45 | 혜택 목록 | 제주 주민이 지역 문화를 더 쉽게 경험 |
| 혜택 시연 | 0:45~1:20 | 해녀박물관 카드 | 요금보다 적용 조건·출처까지 확인 |
| 저장과 데이터 | 1:20~1:45 | 보관함·날씨 | Supabase와 공공 API 3개 연결 |
| AI | 1:45~2:25 | AI 가이드 | 실제 도구 호출과 근거 기반 추천 |
| 한계와 마무리 | 2:25~3:00 | 3D·홈 | 구현 범위와 다음 개선을 명확히 설명 |

## 1 문제와 대상

“제주도민은 도민 할인을 받을 수 있어도 어디서 어떤 조건으로 받을 수 있는지 직접 찾아야 합니다. 같은 도민 혜택이라도 신분증, 나이, 전시 종류와 방문일에 따라 적용 여부가 달라집니다. 저는 이런 확인 과정을 줄이는 제주도민 전용 여행 서비스를 기획했습니다.”

## 2 서비스와 제주 문화

“제주 스토리는 도민 혜택을 우선해 문화·여가 나들이를 찾는 웹앱입니다. 해녀 문화, 제주의 생활사와 돌 문화, 지역 미술관을 중심으로 주민이 제주 문화를 더 쉽게 경험하도록 구성했습니다.”

## 3 혜택 시연

“공식 안내를 확인한 혜택 5곳을 Supabase에 저장했습니다. 해녀박물관을 검색하면 성인 개인 기준 일반 1,100원, 도민 550원이 표시됩니다. 적용 조건과 증빙, 공식 출처와 확인일도 함께 확인할 수 있습니다. 특별전이나 임시휴관 등 예외도 따로 기록했습니다.”

화면 조작: 장소 검색에 ‘해녀’ → 카드 조건 펼치기 → 공식 출처·확인일 지목. 시연 중 외부 사이트를 새로 여는 대신 링크를 보여 주면 시간을 줄일 수 있습니다.

## 4 저장과 데이터

“관심 장소는 보관함에 담아 DB에 저장하고 다시 불러올 수 있습니다. 공공 API는 관광공사 관광정보, 기상청 단기예보, 국가유산청 검색의 세 가지를 사용합니다. 직접 조사한 혜택 DB는 공공 API 개수에 포함하지 않고 별도의 정보원으로 구분했습니다.”

화면 조작: 북마크 → 보관함 → DB 업로드/불러오기 결과 → 준비한 날씨 화면 또는 캡처. 익명 사용자는 브라우저별로 달라지므로 시연 도중 브라우저를 바꾸지 않습니다.

## 5 AI 구간

“AI는 질문에 필요한 관광·날씨·국가유산·도민 혜택 조회 도구를 선택합니다. 배포본에서 실제 질문 7개를 검증했고, 복합 질문에서 도구를 연속으로 호출하는 것을 확인했습니다. 날씨와 해녀박물관 도민 요금을 함께 물으면 화면에 두 도구의 조회 건수가 표시됩니다. 등록되지 않은 에펠탑 할인은 지어내지 않았고, 현대미술관의 임시휴관도 안내했습니다.”

[실측 화면](images/agent-live.png)을 준비합니다. 실시간 질문은 한 번만 하고, 지연이나 장애 시 캡처로 설명합니다. 내일 예보 범위와 답변 길이 한계도 검증 문서에 기록했습니다.

## 6 한계와 마무리

“React Router로 화면을 나누고 Zustand로 공유 상태를 관리했습니다. Supabase와 Vercel을 사용하며, Three.js 제주섬도 구현했습니다. 다만 현재 지도 핀은 예시 위치이고 실제 추천 좌표와 연결하지 않았습니다. 혜택은 확인일 기준 자료이므로 방문 전 공식 안내를 재확인해야 합니다. 다음에는 계정 로그인과 추천 지도 연동을 보완하겠습니다.”
